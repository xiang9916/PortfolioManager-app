# 废除「跨池」池归属：池由市场派生

资金池只有**境内 / 境外**两种取值；`Pool.cross`（跨池）被彻底删除。池不再是手工选择的标的一级属性，而是从标的的**市场**派生出来的：市场为中国内地 → 境内，其余四个市场（US/HK/CN/JP/SG 里除 CN 外）→ 境外；市场解析不出来时按币种回退（CNY → 境内）。

第三态当初是为了安置 `.numbers` 里两张**混币种**的表——「大中华权益」（A股基金 + 港股）与「黄金」（A股黄金ETF + 港股黄金ETF）。它塞不进境内或境外任何一个，于是硬编码了一张「表名 → 池」的映射把它们标成 `.cross`。代价是：`总市值 ≠ 境内 + 境外` 存在一个用户看不见的缺口，优化器的池权重还要额外做一次归一化，资产总览得挂一张「跨池」兜底卡才不会静默丢钱。而 `.numbers` 提取 JSON 里**根本没有**每个持仓的池字段，`market` 字段也从来不存在——所谓「池」从来就是币种口径（提取器自己的 `pool_mode` 就是 `"currency"`，警告原文是「未找到明确的境内/境外资金池表，已按货币分类：CNY=境内，其他=境外」）。按币种把这两张表拆开，A股那两只落境内、港股那三只落境外，正好等于用户手工填出来的现状。

因此：`assets.pool` 列保留（备份、导出、pm-cli 需要一个一致的快照），但**读路径一律不信任它**——UI 与统计都走 `AssetMarket.resolve` / `AssetMarket.pool` 从市场实时派生。市场本身是闭集 `{US, HK, CN, JP, SG}`，由 ticker 形态推断（`.CN_FUND`/`.SZ`/`.SH`/`.SS`/6 位数字 → CN、`.HK` → HK、`.T` → JP、`.SI` → SG、`-USD`/纯字母 → US）或由用户在「新增标的」里选定；自由文本（`NASDAQ`、`LSE`）不再保留，能归一就归一、归一不了就置 NULL。

## Consequences

- 池与股息税率共用同一个市场结论（`DividendTax` 的别名表已并入 `AssetMarket`），结构上不可能再出现「池算境外、税率按 CNY 算 0%」这类分叉。
- 历史 `pool='cross'` 行由 `Database.normalizeAssetClassification()` 在 `migrate()` 收尾时改写；它是幂等的数据补齐，没有结构性变更，因此不占 Schema 版本号。旧 JSON 备份里的 `"pool": "cross"` 由导入路径重新解析，不会报错。
- 「新增标的」不再有池下拉框：市场是唯一入口，改市场就是改池。资产明细详情页多一行只读的「市场」，让派生结果当场可查。
- 「黄金 / 大中华权益可由优化器在两个池之间分配」这条约束仍然成立，但它说的是**优化器的分配自由度**，与已废除的 `Pool.cross` 无关。
