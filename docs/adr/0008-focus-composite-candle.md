# ADR 0008 — 「特别关注」合成日 K 的口径

- 状态：已采纳（2026-10-23）
- 范围：第 4 个 Tab「特别关注」（合成日 K + 当日极值两只）

## 背景

用户要一个「打开就能一眼看到」的资产走势总览：所有资产的**合成日 K（20 根，带上下影线）**
加上**当日涨幅最高 / 跌幅最高**两只的日 K，点击可跳到资产明细。

数据现状决定了这个需求的形状：

- `prices` 过去只有一列 `close`（Yahoo 存 `adjclose`，东财存累计净值），**没有日内开/高/低**；
- 组合本身也没有天然的 OHLC —— 它必须由成分股合成；
- 基金（净值）**结构性没有**日内价，永远画不出影线。

## 决策

1. **数据层补 OHLC**：Schema **v9** 给 `prices` 加可空 `open/high/low`。
   Yahoo 的 `quote[0].open/high/low` 是**原始价**，按当日 `adjclose/close` 因子换算成**复权口径**后入库；
   `close` 的取值口径（`adjclose`，ADR 0005）不变。基金留 NULL。下次「更新行情」自动回补。
2. **归一化基准 = 各标的最新收盘（今收）= 1.00**。因此组合最新一根的收盘恒为 1.00（0%），
   0% 参考线落在图右端，图注写明「相对今收」。
3. **合成 = 逐项加权**：组合的 开/高/低/收 分别 = Σ 权重 × (该资产同名字段 ÷ 该资产今收)；
   权重 = 当前市值折人民币，在参与合成的持仓间重新归一。
4. **无日内价**（基金 / v9 之前的历史行 / 当日休市）：开 = 昨收、收 = 今收、高/低 = 两者较大/较小；
   **当日完全无数据 → 平盘**（开 = 高 = 低 = 收 = 最近收盘），不产生假影线。
5. **窗口固定 20 个交易日**（组合日历 = 各持仓价格日期的并集），不做区间切换。
6. **当日涨跌 = 各标的自己最近两个观测点**的复权收盘变化（境内基金 T+1、各市场休市互不影响）；
   极值只在**有 ≥2 个观测点**的持仓里选，并列按权重降序取第一。
7. **少于两根 bar 的持仓不参与合成**；某标的**首根 bar 之前**的日期也不参与（权重按当天参与者归一）——
   否则等于用一个静态权重稀释组合，或用一个"未来的收盘"往前填出平盘。
8. **两张极值卡画真实现价**（2026-10-24 追加）：Schema **v10** 给 `prices` 加可空 `raw_close`
   （权益 = 未复权收盘价，基金 = 单位净值）。卡片 Y 轴、悬停读数、右上最新价都用它，**不归一化**；
   每根按当日 `rawClose / close` 因子缩放入库的 O/H/L（同一因子 → 精确还原原始价），
   基金无日内价时仍按第 4 条降级。合成卡**不受影响**（它是指数，只有百分比意义）。
   **全有或全无**：窗口内任一根缺原始价就整条退回第 2~4 条的归一化百分比（混画会让一根累计净值
   夹在单位净值中间，出现假尖峰）；顶部涨跌幅继续用 `close`（总回报口径）。

## 理由

- 价格量级差异（4 元的 ETF 与 1200 元的股票）让「直接平均价格」失去意义；先各自归一再加权，
  等价于按收益率加权，也让组合最新点天然对齐到 1.00。
- 基金没有日内数据是结构性事实，退化规则必须写死并可解释，不能靠猜测补出影线。
- 口径集中在 `FocusComposer`（纯函数、不碰数据库），视图只做展示，可用虚构 fixture 单测，
  不会把「某个界面上的数字」变成新的口径来源。

## 后果

- 历史行在下次「更新行情」前 `open/high/low` 为 NULL → 这段时间权益也只有实体、没有影线
  （诚实降级，不编造）。
- 多市场休市日会出现平盘蜡烛 —— 语义正确（那天该市场没有价格变化），但会拉低合成影线的振幅。
- `raw_close` 在 v10 升级后为 NULL，靠**启动时的「更新行情」自动回补**（`startupRefresh`）：
  断网时极值卡先退回归一化百分比，卡片上写明原因 —— 不显示任何"近似真实现价"。
- 基金除息日：价格轴会出现向下跳空（份额净值真实下跌，累计净值不变），而顶部涨跌幅是总回报口径 ——
  两者在那些日子会背离，图注已说明；这是"画真实价格"的必然结果，不是 bug。
- ⚠️ 旧版本二进制（v9 及更早）再写 `prices` 时只写 4~7 列，`INSERT OR REPLACE` 会把
  `open/high/low/raw_close` 重置为 NULL → 需要再用新版本跑一次「更新行情」。
- 不做区间切换 / 自选关注列表 / 周K月K / 分钟线 / 复权开关 / 极值卡的人民币折算价；这些不在本决策范围内。
  （2026-10-29 补充：**区间切换与逐标的归因**已由 ADR 0013 单独决策 —— 归因复用本决策的归一化基准、
  前向填充与当前市值权重，因此「当日」归因的组合涨跌与本决策的 `dayChange` 逐位一致。）
