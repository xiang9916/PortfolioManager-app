# 「总市值 / 总成本」的一键填入只能填当下的实时值

财务分析新增季度时，「总市值」「总成本」两格可以点右侧的 ↓ 按钮一键填入。**填入的是资产总览上此刻的总市值 / 总成本，不是该季末的历史值。**

原因是 App 根本没有历史总市值可用：`snapshots` 表（date / total_value / domestic_value / overseas_value）从建库起就没有任何代码写入过，全仓库只有定义、没有调用；`prices` 表只有逐标的价格，`quarterly_reports` 里的总市值又是人手录入的。要真正还原某个季末的组合市值，就得让 App 每天落一次快照并长期维护——那会把「财务分析」从一份随手记的底稿变成需要后台采集才能成立的子系统，代价远大于它解决的问题。

我们的选择是：只填当下值，并在按钮 tooltip 与图例里**明说**这一点，把「季末那一格要你自己在季末当天点」这件事留在用户手上。也因此，期初基准列（最早的季度）两格都填总成本，维持「期初：总市值 = 总成本」的既有约定。

## Consequences

- 卡片上的总市值随行情跳动，季末那一格是定格的，两者在季末当天会接近但不相等（行情与汇率的更新时点不同）。这是设计意图，不是 bug。
- 往**历史**空列填当下值是错的，所以按钮在空格时常显、已有值时只在悬停出现——覆盖历史数据需要两道动作。
- 若将来真要做历史口径，正确路径是新增每日快照采集，而不是让填入按钮去猜。
